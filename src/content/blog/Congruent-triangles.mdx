Binary Search ทำงานได้เมื่อข้อมูล**เรียงลำดับแล้ว** โดยเปรียบเทียบเป้าหมายกับค่าตรงกลาง:

- ถ้าเท่ากัน → เจอแล้ว
- ถ้าเป้าหมาย **น้อยกว่า** → ตัดครึ่งขวาทิ้ง
- ถ้าเป้าหมาย **มากกว่า** → ตัดครึ่งซ้ายทิ้ง

ทุกครั้งที่เทียบ 1 ครั้ง พื้นที่ค้นหาเหลือครึ่งเดียว จำนวนครั้งสูงสุดจึงเป็น $\log_2 n$

$$
T(n) = T\!\left(\frac{n}{2}\right) + O(1) \;\Longrightarrow\; O(\log n)
$$

## 2. ความเท่ากันทุกประการของรูปสามเหลี่ยม

### 

```python
def binary_search(nums, target):
    lo, hi = 0, len(nums) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            lo = mid + 1
        else:
            hi = mid - 1
    return -1
```

<Callout type="warning">จุดบั๊กคลาสสิกคือ `mid = (lo + hi) / 2` — ในภาษาที่ integer overflow
เป็นไปได้ (C, Java) ให้ใช้ `mid = lo + (hi - lo) / 2` แทน</Callout>

## สรุป

Binary Search คือตัวอย่างแรกของ **Divide and Conquer** — ลดขนาดปัญหาครึ่งหนึ่งทุก step
เข้าใจหลักการนี้แล้ว จะช่วยปลดล็อกโจทย์ optimization อีกมากมายในอนาคต
