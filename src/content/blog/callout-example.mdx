## 1. กล่องข้อมูลพื้นฐาน (info)

ไม่ระบุ prop `type` จะได้กล่องสีน้ำเงินแบบ `info` ใช้สำหรับเน้นข้อมูลเสริมหรือคำอธิบายเพิ่มเติม:

<Callout>นี่คือข้อความแบบ `info` — ใช้เมื่อต้องการเพิ่มข้อมูลที่เป็นประโยชน์แต่ไม่จำเป็นต้องอ่าน</Callout>

## 2. กล่องคำเตือน (warning)

ส่ง prop `type="warning"` จะได้กล่องสีเหลืองสำหรับเตือนให้ระวัง:

<Callout type="warning">ระวัง: อย่าลืมปิดแท็กทุกครั้ง ไม่งั้นข้อความจะแสดงผิดพลาด</Callout>

## 3. กล่องเคล็ดลับ (tip)

ส่ง prop `type="tip"` จะได้กล่องสีเขียวน้ำเงินสำหรับแนะนำเทคนิคหรือวิธีที่ง่ายกว่า:

<Callout type="tip">เคล็ดลับ: ใช้ `type="info"` เป็นค่าเริ่มต้น ไม่จำเป็นต้องระบุก็ได้</Callout>

## 4. ใส่ข้อความยาวหรือหลายบรรทัด

เนื้อหาภายใน Callout เป็น `<slot />` ฉะนั้นสามารถวางข้อความหลายบรรทัดหรือมาร์กดาวน์ปกติได้:

<Callout type="tip">
การวางเนื้อหายาวหลายบรรทัดก็ทำได้ โดยเว้นบรรทัดใหม่หรือพิมพ์ต่อเนื่องกันไปเรื่อย ๆ
```
code ตัวอย่างก็วางในกล่องได้เช่นกัน
```
</Callout>
