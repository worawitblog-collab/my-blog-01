## 1. มุม (Angle)  

 **มุม** เกิดจากการหมุน รังสี (ray) หรือส่วนของเส้นตรง (segment) รอบจุดหมุน ในทิศทวนเข็มนาฬิกา หรือตามเข็มนาฬิกาก็ได้ ดังรูป 1 
 การวัดมุมจะเริ่มจากรังสีเริ่มต้นของการหมุน เรียกว่า **ด้านเริ่มต้น (initial side)** เมื่อหยุดหมุนเรียกรังสีนี้ว่า **ด้านสิ้นสุด (terminal side)**
 การวัดมุม **ถ้าวัดในทิศทวนเข็มนาฬิกาจะได้ค่ามุมเป็นบวก (ดังรูป 1 ด้านซ้าย) ถ้าวัดในทิศตามเข็มนาฬิกาจะได้ค่ามุมเป็นลบ (ดังรูป 1 ด้านขวา)**

```python
def binary_search(nums, target):
    lo, hi = 0, len(nums) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            lo = mid + 1
        else:
            hi = mid - 1
    return -1
```
